# PONAX Bond Fund: Factor Audit and Time-Series Forecasting

Quantitative study of **PIMCO Income Fund (PONAX)**, a multi-sector bond fund that can invest up to 50% in high yield, over **February 2015 to December 2024** (119 monthly observations).

The project answers two questions:

1. **What drives the fund's excess returns?** Equity factors (Fama-French 3 factors) or bond factors (term and default spreads)?
2. **Can the fund's past returns forecast its future excess returns** better than a naive forecast (the historical mean)?

**Full report (PDF):** [reports/ponax_report.pdf](reports/ponax_report.pdf), with the full methodology, test hypotheses and interpretation of every result. The code is in [ponax_audit_forecasting.ipynb](ponax_audit_forecasting.ipynb).

## Key results

### Part I: factor audit

| Model | Factors | Adj. R² | BIC |
|---|---|---|---|
| Fama-French 3 factors | Mkt-RF, SMB, HML | 0.518 | -738.9 |
| **Bond model (retained)** | Mkt-RF, TERM, DEF | **0.669** | **-783.7** |
| Combined model | Mkt-RF, SMB, HML, TERM, DEF | 0.679 | -779.7 |

- Adding two bond factors built from FRED series, **TERM** (rate risk) and **DEF** (credit risk), raises the adjusted R² from 0.52 to 0.67. The bond model has the lowest BIC, so it is retained over the combined model.
- The fund is significantly exposed to the equity market and negatively exposed to changes in term and default spreads (all p < 0.001).
- **Jensen's alpha is not significant** (p = 0.47 with White HC1 robust standard errors): no evidence of manager outperformance once risk factors are accounted for.

Diagnostics run on the retained model:

| Assumption | Test | Result |
|---|---|---|
| Linearity | Residuals vs fitted values, RESET | RESET rejects at 5% (p = 0.018) |
| Homoskedasticity | Breusch-Pagan | Rejected (p < 0.001), so White HC1 standard errors are used |
| Normality of residuals | Jarque-Bera, Q-Q plot | Not rejected (p = 0.12) |
| Influential points | Cook's distance (threshold 4/n) | Flagged observations reported |
| Multicollinearity | VIF | All VIF < 1.2 |
| Autocorrelation | Durbin-Watson, Breusch-Godfrey (6 lags) | DW = 2.05; BG not rejected at 5% (p = 0.065) |

### Part II: time-series modeling and backtest

- **Ljung-Box test (12 lags)** on the bond model residuals: autocorrelation detected (p = 0.001). Some time dynamics are left unexplained by the factor model.
- **ADF test**: the excess return series is stationary (statistic -10.03).
- **ARMA(p, q) grid search** for p, q in {0, 1, 2, 3}: AIC and BIC both select **ARMA(0, 0)**, i.e. a constant mean.
- **Out-of-sample backtest** on the 12 months of 2024 (training set: February 2015 to December 2023):

| Model | RMSE | MAE |
|---|---|---|
| ARMA(0, 0) | 0.0128 | 0.0102 |
| Naive forecast (historical mean) | 0.0128 | 0.0102 |

**Conclusion:** the fund's past returns do not improve the forecast of its future excess returns. The selected model reduces to the historical mean.

**Limitations:** ARMA assumes constant variance and Gaussian errors, but the excess returns show strong heteroskedasticity, negative skewness (-2.03) and fat tails (kurtosis 13.2). Forecast intervals are therefore only approximate. Natural next steps are volatility modeling (GARCH family) and a rolling-window backtest, since 12 test points give limited statistical power.

## Data

| Series | Source | File |
|---|---|---|
| PONAX monthly adjusted prices | Yahoo Finance, downloaded in the notebook with `yfinance` | (none) |
| Fama-French 3 factors and risk-free rate | [Kenneth R. French Data Library](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html) | `data/F-F_Research_Data_Factors.csv` |
| Moody's Baa corporate bond yield | FRED, series `DBAA` | `data/DBAA.csv` |
| 10-year US Treasury yield | FRED, series `DGS10` | `data/DGS10.csv` |
| 3-month US Treasury bill | FRED, series `DTB3` | `data/DTB3.csv` |

Factor construction:

- **TERM** = monthly change in (10-year yield − 3-month yield)
- **DEF** = monthly change in (Baa yield − 10-year yield)
- **Excess return** = monthly log return of PONAX − risk-free rate (Fama-French RF)

## How to run

```bash
pip install -r requirements.txt
jupyter notebook ponax_audit_forecasting.ipynb
```

1. Download the four CSV files listed above into `data/`, and create an empty `results/` folder.
2. Run all cells in order. Part I exports `results/excess_returns.csv` and `results/residuals.csv` (bond model residuals), which Part II reloads. Once these exports exist, Part II can also be run on its own.
3. To rebuild the report with the latest figures, compile `reports/ponax_report.tex` from the `reports/` folder (e.g. `pdflatex ponax_report.tex`, twice for the table of contents).
